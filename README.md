# Pastillero Chocotorro

Dispensador automático de pastillas: disco con 12 cavidades, cono repartidor, celda de carga para confirmar la entrega y ESP32.

Bandeja inclinada que saca la pastilla por la ventana, barredor integrado en la reserva, tapa cuadrada de una pieza y patas y pedestal integrados. |
